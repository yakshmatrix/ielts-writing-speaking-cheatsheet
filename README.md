## 📌 1. The Speaking "A-R-E" Logic Engine (Parts 1 & 3)

Avoid mid-sentence pauses and rambling loops by executing a strict 3-step stack:

* **Answer (Direct Output):** 1 sentence stating your direct position.
* **Reason (The Logic):** 1 sentence explaining *why* that position exists.
* **Example/Elaboration (The Guardrail):** 1 concrete instance.
* **Return 0:** Stop speaking immediately after the example.

## 📌 2. High-Impact Lexical Upgrades

| Basic Band 6.0 Phrase | Band 8.5 Lexical Upgrade |
| :--- | :--- |
| "I think that..." | "From a practical standpoint, it is evident that..." |
| "A big problem is..." | "A predominant issue steming from this is..." |
| "In my opinion..." | "It is widely contended that..." |
| "This causes..." | "This directly precipitates..." |

---

## 📌 3. Task 2 Essay Architecture (4-Paragraph Structure)

1. **Introduction:** Hook/Paraphrase + Direct Thesis Statement.
2. **Body Paragraph 1:** Core Argument + Logical Explanation + Specific Example.
3. **Body Paragraph 2:** Secondary Argument/Counterpoint + Logical Explanation + Impact.
4. **Conclusion:** Restate Thesis + Final Synthesis (Zero new arguments).
